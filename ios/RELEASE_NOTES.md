# v0.2.0 — 背景・ポーズ・キャラ設定

**対象:** iOS（iPhone）  
**配布:** TestFlight（[参加リンク](https://testflight.apple.com/join/gqmp9uUA)）

背景に **カメラ映像** や **同梱の既定画像** を使えるようになりました。**ポーズ** の声かけや、キャラ **ミャー**（旧ミク）の設定更新も含みます。

## ハイライト

- **背景** — **カメラの映像**／写真／**背景を既定に戻す**（キャラごと）
- **ポーズ** — 「ポーズして」で順番にポーズ
- **ミャー** — 2 人目のキャラ名を変更。ファンタジー世界の冒険設定
- **はるか** — 初期表示をバストアップに

## 背景

ギア → キャラ → **背景** から設定します。


| 操作           | 内容                     |
| ------------ | ---------------------- |
| **カメラの映像**   | 背面カメラのライブ映像を背景に（初回は許可） |
| **写真を選ぶ**    | 端末の写真を背景に              |
| **背景をやめる**   | 背景をオフ                  |
| **背景を既定に戻す** | 同梱の既定画像（または背景なし）に戻す    |

# v0.1.0 — iOS 初回リリース

**対象:** iOS（iPhone）  
**配布:** TestFlight（[参加リンク](https://testflight.apple.com/join/gqmp9uUA)）

VRM キャラクターと Gemini Live で、iPhone 上でリアルタイムに音声会話できるアプリです。

## ハイライト

- **音声会話** — マイクに話しかけると、表情・口パク付きで応答
- **4 人のキャラ** — アイ／ミャー／はるか／ヒロ。設定・記憶はキャラごと
- **声かけ** — タイマー、アラーム、ToDo、天気、ニュース、調べもの
- **割り込み・ミュート** — AI 発話中に話しかけ可能。ミュートは画面上のマイクまたは「ミュートして」
- **見た目** — ピンチ・スワイプでカメラ調整、背景（カメラ映像・写真・既定）、VRoid Hub のモデル
- **ポーズ** — 「ポーズして」で順番にポーズをとる



## 必要なもの


| 項目                | 内容                                                                                              |
| ----------------- | ----------------------------------------------------------------------------------------------- |
| **Gemini API キー** | 設定（ギア）→ **Gemini API キー** で保存。[Google AI Studio](https://aistudio.google.com/app/apikey) で無料取得可 |
| **マイク権限**         | 初回起動時に許可                                                                                        |
| **TestFlight**    | テスト版のインストールに必要                                                                                  |


> API キーが未設定・無効な場合、会話できません。



## はじめ方

1. [TestFlight 参加リンク](https://testflight.apple.com/join/gqmp9uUA) からアプリをインストールする。
2. 起動し、**Gemini API キー** を設定する。
3. マイクに向かって話す。

手順の詳細は [TestFlight.md](TestFlight.md) を参照。

## 主な声かけ


| 例             | 動作              |
| ------------- | --------------- |
| 「3分後に教えて」     | タイマー            |
| 「9時にアラーム」     | アラーム（iOS 26 以降） |
| 「買い物を予定に追加して」 | ToDo            |
| 「東京の明日の天気」    | 天気予報            |
| 「国際ニュース教えて」   | ニュース見出し         |
| 「〇〇について調べて」   | ブラウザで検索         |


詳細は [README.md](README.md) を参照。
