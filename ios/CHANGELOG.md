# Changelog

## [0.2.0] — 背景・ポーズ・キャラ設定

**リリース名:** 背景・ポーズ・キャラ設定  
**対象プラットフォーム:** iOS（iPhone）

### Added

- **背景にカメラ映像** — 設定 → **背景** → **カメラの映像**（初回はカメラの許可が必要）
- **同梱の既定背景** — キャラごとに最初から背景画像（未変更時）
- **背景を既定に戻す** — 写真・カメラ映像・背景オフをやめて、既定背景に戻す
- **ポーズ** — 「ポーズして」で順番にポーズ（**機能** でオフ可）

### Changed

- **キャラ2** — 表示名を **ミャー** に。ファンタジー世界の冒険仲間として会話（語尾に「〜にゃ」など）
- **はるか・ヒロ** — 初期のキャラ設定（同級生など）を更新
- **はるか** — 切替・位置を戻すとき、顔が画面中央付近のバストアップ表示
- **上部 HUD** — マイク表示を画面中央に固定
- **声の高さ** — 女性キャラの初期ピッチを自然な高さに

## [0.1.0] — iOS 初回リリース

**リリース名:** iOS 初回リリース  
**対象プラットフォーム:** iOS（iPhone）

### Added

- Gemini Live によるリアルタイム音声会話（4 人のキャラクター）
- 設定メニュー（API キー、キャラ切替、性格・音声・記憶・好感度など）
- 会話の割り込み、ミュート（画面上のマイク／音声指示）
- 会話モード（雑談／作業応援／お悩み相談／音楽鑑賞／集中）
- 記憶（会話から自動整理）、ToDo
- タイマー、アラーム（iOS 26 以降）
- 天気予報、ニュース見出し、Web 検索（明示依頼時）
- カメラ操作（ピンチ・スワイプ）と背景写真
- VRoid Hub 連携、声の高さ調整（女性）
- ポーズ撮影（「ポーズして」でシーケンス開始）
