# VrmAiFriend（iOS）

VRM キャラクターと Gemini Live で、iPhone 上でリアルタイムに音声会話できるアプリです。  
**iOS 専用**（Windows / macOS 版とは別アプリです）。

## 必要なもの

| 項目 | 内容 |
| ---- | ---- |
| **Gemini API キー** | 設定（ギア）→ **Gemini API キー** で保存 |
| **マイク権限** | 起動時に許可 |

> API キーが未設定・無効な場合、会話できません。キーは端末内に暗号化して保存されます。

## インストール（TestFlight）

1. App Store から **TestFlight** をインストールする。
2. [TestFlight 参加リンク](https://testflight.apple.com/join/gqmp9uUA) から VrmAiFriend をインストールする。
3. 起動し、マイクを許可する。

詳細は [TestFlight.md](TestFlight.md) を参照。

## 使い方

1. 初回起動時、**Gemini API キー** を入力して保存する（ギア → **Gemini API キー**）。
2. 画面上部の **マイク** が緑になれば、話しかけられる状態です。
3. マイクに向かって話す。

上部には **会話モード**（左）、**マイク**（中央）、**ギア**（右）があります。ギアからキャラの切替・各種設定ができます。

## 主な機能

### 会話の割り込み

AI が話している最中に話しかけると、再生を止めてあなたの発話を優先します。

### ミュート

| 操作 | 方法 |
| ---- | ---- |
| ミュート | 上部の **マイク** をタップ、または「ミュートして」などと話す |
| 解除 | **マイク** をタップ。女性キャラでは顔・胸タッチでも解除 |

ミュート中は画面下に「Mute」と表示されます。

### キャラクター

アイ／ミク／はるか／ヒロの 4 人から選べます。性格・音声・記憶・好感度・ToDo はキャラごとに保存されます。

### タイマー・アラーム・ToDo

| 例 | 動作 |
| ---- | ---- |
| 「5分後に教えて」 | タイマー |
| 「15時にアラーム」 | アラーム（**iOS 26 以降**） |
| 「〇〇を予定に追加して」 | ToDo |

設定の **機能** で各機能のオン／オフを切り替えられます（キャラごと）。

### 天気・ニュース・調べもの

| 例 | 動作 |
| ---- | ---- |
| 「横浜の一週間の天気」 | 天気を会話で答える |
| 「経済ニュース教えて」 | 見出しを会話で答える |
| 「〇〇について調べて」 | ブラウザで Google 検索を開く |
| 「Yahooニュースを開いて」 | ニュース一覧をブラウザで開く |

「教えて」だけではブラウザは開きません。調べものは「調べて」「ブラウザで開いて」などと明示してください。

### 記憶

会話が区切れると、今後の会話に役立つ内容が自動で整理・保存されます。ギア → **記憶** で確認・削除できます。

### カメラと表示

| 操作 | 動作 |
| ---- | ---- |
| ピンチ | 寄る／離れる |
| 1 本指スワイプ | 角度を変える |
| 2 本指パン | 位置をずらす |

ギア → **背景** で写真を背景にできます。ギア → **位置を戻す** で標準の見え方に戻せます。

### VRoid Hub

ギア → **モデル** から、Hub にログインして自分のモデルや ♡ したモデルに切り替えられます。
