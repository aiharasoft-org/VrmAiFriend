
# VrmAiFriend (iOS版)

VRM キャラクターとリアルタイム会話ができる iPhone（iOS）専用のAIアシスタントアプリです。  
会話から表情が滑らかに変化し、会話の積み重ねによって好感度も変化します。タイマー、アラーム、ToDo管理、天気予報、ニュース見出し、Web検索などの声かけや各種操作に対応しています。

## 対応プラットフォーム

| プラットフォーム         | 備考          |
| ---------------- | ----------- |
| **iOS / iPhone** | iPhone専用アプリ |

※ Windows や macOS には対応していません。

---

## 初期設定・準備

起動前に以下をご用意・ご確認ください。

| 項目                | 内容                          |
| ----------------- | --------------------------- |
| **Gemini API キー** | アプリ内の設定メニューで入力・保存します。       |
| **マイク権限**         | アプリ起動時にマイクへのアクセス許可を認めてください。 |

> **注意:** Gemini API キーが未設定、または無効な場合、AIとの会話機能を利用できません。

---

## 使い方・主な機能

1. アプリを起動します。
2. 設定メニューで Gemini API キーを設定・保存します。
3. マイクに向かって話しかけると、アバターが音声と口パク・表情の変化を交えて応答します。

### 会話の割り込み・応答
- AI が話している最中に話しかけると、音声を停止してあなたの発話を優先します。
- 接続待ち状態（Standby）の際に画面上のアバターをタッチすると、再接続やリアクションを行います。

### 音声・発話の調整
- **ミュート**: マイク入力のオン/オフを切り替えられます。
- **声の高さ**: 音声指示でキャラの声の音調・高さを変更できます。

## 機能一覧（外部仕様）

| 機能 | 説明 |
| ---- | ---- |
| **タイマー** | 「〇分後に教えて」などの指示でタイマーをセットし、時間になったら音声でお知らせします。 |
| **アラーム** | 指定した時刻にアラームを設定・お知らせします。 |
| **ToDo** | タスクの追加・確認・整理を会話を通じて行えます。 |
| **天気予報** | 地域や日付（今日・明日・週間など）を指定して天気を教えてくれます。 |
| **ニュース見出し** | 最新カテゴリ別のニュース見出しの確認や、気になった記事のブラウザ閲覧ができます。 |
| **Web 検索** | 詳しい情報が必要な話題について、既定のブラウザを開いて検索できます。 |
| **アプリ・サイト起動** | 許可された特定のアプリやWebサイトを開くことができます。 |
| **記憶（長期記憶）** | 会話内容を自動で整理・記憶し、次回の会話や振返りに反映します。 |
| **カメラと表示（iOS）** | アングル調整や表示モードの切り替えを行えます。 |
| **設定メニュー（iOS）** | APIキー設定、キャラクターの切り替え、各種パラメータの調整を行えます。 |
