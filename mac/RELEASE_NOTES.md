# v1.0.0 — 初版

**対象:** macOS

VRM キャラクターと音声でリアルタイム会話できるデスクトップコンパニオンの初版リリースです。

## 主な機能

- **会話の割り込み** — AI 発話中に話しかけると、再生を止めて会話を優先
- **ミュート** — 「ミュートして」、`Option` + `M`、顔・胸タッチで解除
- **接続待ちとタッチ** — 待機ポーズ中のタッチで再接続・反応
- **マイク** — 状態確認、音声レベル、感度調整
- **Web 検索** — 詳しく答えきれないとき Google 検索結果を開く
- **アプリ・サイト起動** — 許可されたアプリ・サイト・監視ツールを開く
- **ニュース見出し** — 見出しを聞く、記事や一覧を開く

## インストール

[Aivis Speech Engine](https://github.com/Aivis-Project/AivisSpeech-Engine) の起動、Gemini API キーの保存、物理マイクの準備が必要です。手順は [README.md](README.md) を参照してください。
