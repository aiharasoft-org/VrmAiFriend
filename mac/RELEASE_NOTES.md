# v0.9.8 — キャラ設定の整理と初期化の見直し

**対象:** macOS

キャラごとの設定画面を整理し、会話モードの保存や「初期に戻す」の対象を分かりやすくしました。バージョンとヘルプはメニューバーから開けます。

## ハイライト

- **4 人のキャラ** — アイ／ミャー／はるか／ヒロ。設定はキャラごとに保存
- **会話モード** — メニュー上部にいまのモードを表示。**適用する** または画面を離れたときに保存
- **アプリを開く** — 機能メニューで、声によるアプリ・サイト起動をオン／オフ
- **初期に戻す** — そのキャラの設定に加え、会話ログと記憶も空になる（確認後）
- **メニューバー** — About とヘルプ。**Window** から透過も切替
- **見た目の復元** — 再起動やキャラ切替で表示が戻らないことがある問題を改善

## インストール

1. [公式ページ](https://aiharasoft.com/VrmAIFriend/Mac/) または [GitHub Releases](https://github.com/aiharasoft-org/VrmAiFriend/releases) から macOS 版をダウンロードする
2. zip を展開して `.app` を起動する（Apple Silicon / Intel 両対応）
3. [Aivis Speech Engine](https://github.com/Aivis-Project/AivisSpeech-Engine) を起動し、マイク権限を許可する
4. **設定** タブで Gemini API キーを保存する

公証済みのため、通常はダブルクリックで開けます。止まる場合は **Control + クリック** → **開く** を試してください。

## アップグレード時の注意（v0.9.6 → v0.9.8）

- キャラの設定は 4 人それぞれに保存されます
- **初期に戻す** は会話ログと記憶も消します（確認後。取り消せません）
- バージョン表示とヘルプは OS のメニューバーにあります

詳細は [README.md](README.md) を参照してください。
