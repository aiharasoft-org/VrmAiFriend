# VrmAiFriend（macOS）

VRM キャラクターと Gemini Live でリアルタイム会話できるデスクトップコンパニオンです。AI の声は **Aivis Speech** で再生されます。

## 必要なもの

| 項目 | 内容 |
| ---- | ---- |
| **Aivis Speech Engine** | 必須。インストールして起動しておく。[AivisSpeech Engine](https://github.com/Aivis-Project/AivisSpeech-Engine) |
| **Gemini API キー** | メニュー **設定** タブで保存 |
| **物理マイク** | 必須（仮想オーディオのみでは不可） |

> Gemini API キーが未設定・無効な場合、会話できません。

## インストール

1. [VrmAiFriend](https://github.com/aiharasoft-org/VrmAiFriend) から **macOS 版** をダウンロードする。
2. `.app` を起動する。Gatekeeper で止まる場合は **Control + クリック** → **開く**。
3. **AivisSpeech Engine** を起動し、**システム設定** → **プライバシーとセキュリティ** → **マイク** で VrmAiFriend を許可する。

## 使い方

1. Aivis Speech Engine を起動する。
2. アプリを起動し、**設定** タブで Gemini API キーを保存する。
3. **設定** タブの **マイク** が `OK` になることを確認する。
4. マイクに向かって話す。

`ESC` でメニューとウィンドウ透過を切り替えられます。

## 主な機能

### 会話の割り込み

AI が話している最中に話しかけると、再生を止めてあなたの発話を優先します。スピーカー利用時は **マイク感度を調整** を推奨します。ダンス中は会話はできますが、ダンスは止まりません（「ストップ」などで停止）。

### ミュート

| 操作 | 方法 |
| ---- | ---- |
| ミュート | 「ミュートして」などと話す、または `Option` + `M` |
| 解除 | `Option` + `M`、または顔・胸をタッチ |

ミュート中は画面中央下に「Mute」と表示されます。

### 接続待ちとタッチ

接続のつなぎ直し待ち中、キャラが待機ポーズをとることがあります。その最中にタッチすると、接続が切れていれば再接続を始め、待機ポーズをやめて反応します。反応後は通常の立ち姿に戻ります。

### マイク

**設定** タブで状態（`OK` など）・**音声レベル**・**マイク感度を調整** が使えます。調整結果は保存され、再起動後も引き継がれます。

### Web 検索

「〇〇について教えて」「〇〇を調べて」など、詳しく答えきれないとき Google 検索結果をブラウザで開くことがあります。「ブラウザを開いて」は検索なしでブラウザを起動します。

### アプリ・サイト起動

許可されたアプリ・サイトだけ開けます。

| 例 | 結果 |
| ---- | ---- |
| 「メモ帳起動して」「電卓」「ターミナル」 | 対応アプリを起動 |
| 「GitHub」「ノートを開いて」 | 登録済みサイトを開く |
| 「アクティビティモニターを開いて」 | アクティビティモニタを開く |

任意の URL や許可外のアプリは開けません。

### ニュース見出し

| 例 | 結果 |
| ---- | ---- |
| 「今日のニュース」「国際ニュース教えて」 | 見出しを会話で答える（ブラウザは開かない） |
| 「〇〇の記事を詳しく」（直前に聞いた見出し） | 近い記事をブラウザで開く |
| 「Yahooニュースを開いて」 | トピックス一覧を開く |
