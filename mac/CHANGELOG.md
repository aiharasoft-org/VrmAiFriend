# Changelog

## [0.9.8] — キャラ設定の整理と初期化の見直し

**対象:** macOS

### Added

- **会話モード表示** — メニュー上部にいまのモード名。タップで会話モード画面を開く
- **機能の「アプリを開く」** — 声によるアプリ・サイト起動をオン／オフできる
- **メニューバー** — About（バージョン）とヘルプ。**Window** から透過も切り替えられる

### Changed

- **キャラメニュー** — アイ／ミャー／はるか／ヒロの 4 人。設定はキャラごとに保存する
- **会話モード** — モードと間隔は **適用する**、または画面を離れたときに保存する
- **初期に戻す** — そのキャラの設定に加え、会話ログと記憶も工場出荷の状態へ（確認後。取り消せない）
- **メニュー折りたたみ** — 畳んでいるあいだもタッチリアクションが使える
- **見た目** — 再起動やキャラ切替で VRM が表示されない・切り替わらないことがある問題を改善
- **配布** — Apple の公証済み。Apple Silicon と Intel の両方で起動できる
